## Architecture and data flow

The public README and fetcher report describe a TypeScript-first local desktop application direction with a Next.js frontend, Node/TypeScript backend/API, embedded PGlite with pgvector, and local filesystem storage. The legal-data flow described by the project centers on source ingestion, normalization, parsing, chunking, embeddings, and retrieval with citations.

Public source categories mentioned by the README include Normattiva Open Data, Gazzetta Ufficiale, EUR-Lex, and jurisprudence where available. Normattiva Akoma Ntoso data is a key format in the proposed parsing and knowledge-graph flow.
