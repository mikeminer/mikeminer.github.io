# Multi Crypto Compare

## Executive summary

Multi Crypto Compare is described as a Web3 analytics platform for multi-asset crypto comparison, portfolio intelligence, API integration, wallet EVM analysis, Hyperliquid signal analysis, rebalancing evaluation, and read-only decision support.

## Problem, users, and constraints

The project targets users who need clearer comparison and analysis across crypto assets, wallets, and trading signals. The most important stated constraint is safety: the system is described as read-only, with no custody, no private-key handling, no transaction signing, and no order execution.

## Personal role and ownership

Available sources support Michele as builder and product designer. The project fits his risk-systems and Web3 analytics direction.

## Architecture and data flow

The public CV/context describes a stack including Next.js, TypeScript, Tailwind CSS, shadcn/ui, Prisma, PostgreSQL, Zod, TanStack Query, Zustand, API routes, caching, local market engine, and Web3 wallet login.

Additional developer-facing layers include Go SDK, Python SDK, Streamlit + Ollama tooling, API exploration, script generation, Telegram alerting, desktop tool support, and a possible future external execution-engine integration.

## Technology choices

The project combines web app infrastructure, typed frontend/backend code, persistent data modeling, API exploration, local AI/tooling support, and Web3 wallet context. The read-only architecture is a key career signal because it separates analytics from execution risk.
